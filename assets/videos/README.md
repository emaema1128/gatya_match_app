# ガチャ演出用の動画素材

`gacha_screen.dart` の「ガチャる」演出の冒頭(ドラゴンが飛び回る〜雷〜火を吹く、の部分)は
このフォルダに置いた動画ファイルを再生する。

- 配置するファイル名: `gacha_doragon_intro.mp4`
- このファイルが無い場合は自動的にスキップされ、これまで通り機体+カプセルの演出から始まる
  (クラッシュはしない)。
- 推奨: 縦長(9:16程度)、3〜5秒程度の短さ。長すぎるとタップから結果が出るまで待たされて冗長に感じる。
- 音声ありでそのまま再生される(雷鳴などの効果音を含めてよい)。再生中は右上に「スキップ」ボタンが出る。
